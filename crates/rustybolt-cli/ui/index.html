Global profile overrides
Key and value pairs written into every RuneLite profile before each launch, so every profile on this machine gets the same values. Any RuneLite setting works: the key is the plugin name, a dot and the setting name, as in RuneLite's own profile files. A backup of each changed file sits next to it with a .bak suffix.
